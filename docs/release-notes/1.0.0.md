## Continue working

After saving, choose your next tool and click **Continue**. Organize pages, compress the result, then split it to fit an upload limit without reopening the saved files.

## What's new

- **Split by file size.** Create PDFs that fit a chosen upload limit, with every page kept in order.
- **Check compression before saving.** See the resulting size and compare original and compressed pages.
- **Save upload limits.** Name common limits and reuse them.
- **Review pages.** Find possible blank or duplicate pages, review split outputs, and name the files before saving.
- **Compare PDF text.** Review changed passages between an original and revised document, with links to the source pages.

Compare checks extracted text, not images, formatting, or form-field values. Scans need a text layer. Page-check findings require review; no pages are removed automatically.

## Improvements

- Extra controls stay tucked away until needed, with an optional page preview beside your work.
- Improved image compression and removal of unused PDF resources.
- Mixed imports keep valid files and identify files that could not be added.
- Large merged outputs can exceed the individual input-file limit.
- Saving detects disconnected or changed output folders.

## Install

[Download PDF Tools for Apple Silicon Macs](https://github.com/el-jsn/offline-pdf-tools/releases/download/v1.0.0/PDF-Tools_1.0.0_macos-arm64.dmg), including M1 through M4.

Quit PDF Tools, open the DMG, and drag the app to Applications. Existing users can also choose **Check for updates**.

This build is not Apple notarized; macOS security approval may be required.
