## Error details for skipped files

**Copy error details** now appears when files are skipped during import, including when every selected file is rejected. It works with the file picker, drag-and-drop, and mixed batches of accepted and skipped files.

The copied report includes recognized engine warnings and the import failure reason. Filenames, paths, passwords, and document-derived strings are excluded.

[Download for Apple Silicon Macs](https://github.com/el-jsn/offline-pdf-tools/releases/download/v1.0.3/PDF-Tools_1.0.3_macos-arm64.dmg), or choose **Check for updates**.
