## Copy error details

If processing or validation fails, click **Copy error details** beneath the status message and send the report to IT.

The report includes the failed step, compression setting, file sizes and page counts, engine exit codes, and recognized warnings. Filenames, paths, passwords, and document-derived strings are excluded. Unrecognized raw diagnostic text is omitted. Nothing is sent automatically or saved to a log file.

Engine output is now captured with a size limit while excess output is safely drained. Validation requirements remain unchanged.
