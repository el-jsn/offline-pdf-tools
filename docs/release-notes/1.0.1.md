## What's new

- **New app icon.** Light and dark versions follow the app's Appearance setting in the Dock while PDF Tools is running.
- **Simpler theme controls.** Switch between System, Light, and Dark with compact, rounded buttons and a subtle grayscale selection.
- **Share the app.** Use the small share button in the sidebar to copy the latest download link.
- **Fewer interruptions.** Accessibility-tag notices no longer require an extra checkbox. Digital signature removal still requires confirmation, now labelled **Remove digital signatures**.

## Install

[Download PDF Tools for Apple Silicon Macs](https://github.com/el-jsn/offline-pdf-tools/releases/download/v1.0.1/PDF-Tools_1.0.1_macos-arm64.dmg), or choose **Check for updates** in the app.

For manual installation, quit PDF Tools, open the DMG, and drag the app to Applications.

This build is not Apple notarized; macOS security approval may be required.
