## Compare saved form answers

Compare PDFs now detects changes to saved text fields, dropdowns, checkboxes, and radio selections alongside page text. Results show each changed field's original and revised values, with links to its source pages. Cleared, added, and removed fields are also reported.

Comparison remains local. Images, annotations, formatting, signatures, field appearance streams, and XFA forms are not compared.

Validated against a local PDF pair with five changed text fields and one changed checkbox, plus focused checks for field matching and text comparison. Original PDFs remain unchanged.

[Download for Apple Silicon Macs](https://github.com/el-jsn/offline-pdf-tools/releases/download/v1.1.5/PDF-Tools_1.1.5_macos-arm64.dmg), or choose **Check for updates**.

This Mac build uses ad-hoc signing and is not Apple Developer ID signed or notarized. Windows and Intel Mac packages are not included.
