# PDF Tools 1.1.0

- Improved Balanced and Smaller compression with image, embedded-font, and PDF structure optimization.
- Expanded support for image placements inside nested PDF graphics.
- Upload limits now try resolutions down to the selected preset's minimum.
- Compressed copies are checked for saved form values, bookmarks, attachments, and retained document structure before saving.

Processing stays local. Original quality continues to use lossless structural compression.

This release includes the Apple Silicon Mac installer and signed in-app update.
The Mac app uses the same ad-hoc signing as previous releases; it is not Apple notarized.
