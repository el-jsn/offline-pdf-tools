# Project instructions

- Do not use text glyphs for icons. Use SVG assets.
- Run builds only when the user explicitly authorizes them. The user authorized builds while diagnosing the Mac release in this conversation. Do not run broad test suites. Small checks for individual files are allowed.
- Keep a single light theme and follow Apple's Human Interface Guidelines.
- All PDF processing and previews must remain local. No uploads, analytics, accounts, or runtime downloads.
- Do not overwrite original documents or existing output files.
- Keep customer PDFs out of Git and document limitations accurately.
- Keep UI copy concise. No slogans, marketing copy, repeated reassurance, or unnecessary instructions. Show details only when relevant.
